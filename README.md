# 🌱 Sunny Farm & Metaverse 3D Online (v3.0 - Exact Cozy HTML UI & 3D Visuals)

Phiên bản **v3.0** đồng bộ **100% giao diện Cozy Cream/Amber, bầu trời xanh ngọc, mây 3D trôi bồng bềnh, vòng dịch chuyển phát sáng, bảng Điều Khiển Khu Vực và khung Chat góc dưới phải** giống hệt bản HTML gốc, đồng thời tích hợp đầy đủ:
1. **Đăng nhập bằng Google (Supabase OAuth + Cloud Save)**.
2. **Supabase Realtime (Presence & Broadcast)** cho Multiplayer qua Internet.
3. **Nạp mô hình 3D `.glb` (`useGLTF` & `useAnimations`)**.
4. **Hệ thống Chăn nuôi Gia súc 3D (Bò sữa, Cừu, Gà)** và Modal Kho Nông Sản (`🎒 Kho`).

## 🚀 Chạy ngay tại Local
```bash
npm install
npm run dev
```
Truy cập `http://localhost:3000`.
